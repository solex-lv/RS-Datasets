## Notes

- **VHM-Instruct**: A comprehensive multimodal instruction dataset for remote sensing tasks
- **RSVQA**: Contains both High Resolution (HR) and Low Resolution (LR) versions for remote sensing visual question answering
- **DIOR-RSVG**: An extension of the DIOR dataset specifically for remote sensing visual grounding
- For specific train/test splits, please refer to the official dataset documentation
